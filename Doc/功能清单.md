# NewLife.Cube.WeCard 功能清单

对照官方自建文档树：`https://wiki.weixiao.qq.com/api/selfbuilt/`。状态：☐ 未做 / ☑ 已做。

首版按已确认范围覆盖 P0–P3。支付、门禁、来访、缴费为薄封装（客户端方法 + 回调挂钩），不建业务表，不默认开通支付。第三方 `/api/third*` 不在清单内。

## 指南与基础（P0）

| 能力 | 文档 | 状态 |
|------|------|------|
| 概述 / 基本概念 / 接入规范 | guides/epitome, basicConcept, standard | ☑ README 与 Options 对齐，不含第三方 |
| 获取应用有效凭证 access_token | guides/accessToken | ☑ `GetAccessTokenAsync`，按 ocode 缓存 |
| 事件推送总述 | guides/event | ☑ `/WeCard/Callback`，`WeCardEventNames` |
| 对称/非对称加解密、签名 | pay/crypt/*、tools/crypt、tools/signAlgorithm | ☑ `WeCardCrypt` / `WeCardPayCrypt` / `WeCardSign` |
| 错误码/返回码约定 | accessToken 错误码 | ☑ `WeCardErrorCodes`，`code`/`errcode` 非 0 抛 `WeCardException` |

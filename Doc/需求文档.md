# NewLife.Cube.WeCard 需求文档

## 1. 背景与目标

在 GitHub 账号 `gz-hcyk` 下新建公开仓库 **NewLife.Cube.WeCard**，实现腾讯微卡**自建应用**开放能力对接，作为 [NewLife.Cube 魔方](https://github.com/NewLifeX/NewLife.Cube) 的功能扩展包：任意新建魔方项目引用并注册后即可调用微卡接口、接收事件回调。

官方入口：[腾讯微卡开放平台概述（自建）](https://wiki.weixiao.qq.com/api/selfbuilt/guides/epitome.html)  
文档根目录：`https://wiki.weixiao.qq.com/api/selfbuilt/`（与历史 `/api/self/` 内容对应，以 selfbuilt 为准）。

参考实现风格：已有公开扩展 [NewLife.Cube.QyWeixin](https://github.com/gz-hcyk/NewLife.Cube.QyWeixin)（双 NuGet、Add/Use 注册、Doc 三件套、P0–P3 分批、单测不打真网）。

## 2. 干系人与使用场景

| 角色 | 诉求 |
|------|------|
| 学校/企业魔方宿主开发者 | 引用 NuGet，配置 AppKey/AppSecret/ocode，调用组织、成员、认证、消息、支付等 API |
| 运维 | 在微卡后台配置回调 URL、业务域名；在魔方配置凭据 |
| 本库维护者 | 文档与官方接口一一对照，可打包、可测、可扩展 |

典型场景：通讯录同步到魔方用户/部门、H5/小程序 OAuth 取身份态、事件推送落库、电子码扫码通知、消息通知、（可选）支付/门禁薄封装。

## 3. 范围

### 3.1 纳入（自建应用 selfbuilt）

按官方侧栏模块，**首版目标覆盖「自建应用」文档树中的服务端对接能力**（见《功能清单》），分批交付：

- **P0**：凭证、签名/加解密、错误码约定、客户端骨架、回调验签与事件分发、薄宿主 `AddWeCard`/`UseWeCard`
- **P1**：OAuth（H5/PC/小程序）、管理员登录态、主体信息、组织架构与成员查询/搜索、身份类型、事件推送（成员/组织）
- **P2**：角色/角色组、标签、权限组、物理卡、信息同步（推送/拉取相关）、电子卡/校园码、消息通知（公告）
- **P3**：支付相关（代扣/混合支付/充值等）、门禁、来访等线下能力（薄封装，不绑具体业务表）

### 3.2 明确不纳入（除非另开需求）

- 第三方应用（`/api/third*`）与服务商代开发全链路（与自建密钥模型不同）
- 运营后台 UI 皮肤、微卡官方运营指南类非 API 文档
- 真实支付清算对账产品、硬件驱动、小程序前端工程（仅提供服务端 API 与回调）
- 修改 NewLife.Cube 框架源码

## 4. 非功能需求

- 目标框架：`net8.0`；魔方依赖版本与同账号其它扩展对齐（当前参考 `6.15.2026.901`）
- 装包即用；用户/角色/权限/审计仍用魔方，本库不重建账号体系
- 凭据不入库明文到公共示例；配置走魔方配置或 Options
- 单测默认不访问 `open.wecard.qq.com`；加解密/签名/回调解析必须有单测
- 支持主体**公有云**网关；私有化网关域名（`私有化域名+/kong`）通过 Options 可配置 BaseUrl
- 文档：`Doc/需求文档.md`、`功能清单.md`、`架构设计.md` 与代码同步

## 5. 验收标准（首版可合并 main 的最低门禁）

1. 公开 GitHub 仓存在，README 说明安装与 `AddWeCard`/`UseWeCard`
2. P0+P1 接口有对官方路径的客户端方法 + 功能清单勾选
3. 回调端点可验签/解密并分发到 handler；返回码符合微卡约定
4. `dotnet test` 绿；`dotnet pack` 产出至少一套可用 nupkg（是否双包 MVC/WebApi 见架构确认项）
5. 示例宿主能编译启动（可用假凭据；真联调可选）

## 6. 已确认项

- 包形态：双 NuGet。`CubeHost=Mvc` → `NewLife.Cube.WeCard` 依赖 `NewLife.Cube.Core`；`CubeHost=WebApi` → `NewLife.Cube.WeCard.WebApi` 依赖 `NewLife.Cube`。程序集名与公开 API 相同。
- 首版范围：P0–P3，含支付、门禁、来访的薄封装。
- 仓库：`https://github.com/gz-hcyk/NewLife.Cube.WeCard`。不发布 nuget.org，不提交真实 AppSecret。
